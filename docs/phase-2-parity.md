This inventory compares source at immutable commits. Deployment feature flags, credentials, data, and actual production responses were outside the audit.

The Java stacks use permanent RDF IRIs for concept identity and distinguish asserted, inferred, alignment and provenance graphs. Django v1 uses slugs and relation UUIDs. Django public v2 uses a separate UUID-addressed relational publication. The archived graph deep links use release-scoped computing IRIs that can contain UUIDs. A reviewed crosswalk is required for identity-specific compatibility redirects or schema adapters. During staging, existing public origins retain their original consumers and contracts.
